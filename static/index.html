Atualização do RouterOS

Verificando…

Como atualizar: faça um backup, escolha um horário sem aula e, no Winbox, abra System → Packages → Check For Updates → Download&Install. O roteador reinicia sozinho (a rede para por alguns minutos). Depois, para o firmware: System → RouterBOARD → Upgrade e reinicie de novo (System → Reboot).

Forçar o DNS do roteador

Faz o bloqueio valer também para quem configurou outro DNS no aparelho (ex.: 8.8.8.8): toda consulta DNS vinda do hotspot é atendida pelo MikroTik. Não afeta a rede da secretaria. Pode desligar e religar a qualquer momento.

Carregando…

O bloqueio vale para o site e todos os subdomínios (bloquear tiktok.com bloqueia também www.tiktok.com, m.tiktok.com etc.) e funciona pelo DNS do MikroTik: aparelhos configurados com outro DNS (8.8.8.8, DNS privado) não são afetados. Pode levar alguns minutos para valer em quem já tinha aberto o site.

Cópias de segurança

O painel guarda sozinho uma cópia por dia (no primeiro login do dia) com os usuários e senhas, aparelhos, perfis e sites bloqueados, e mantém as últimas 30 na pasta dados\backups deste computador. Restaurar recria no MikroTik só o que estiver faltando; não altera nem apaga o que já existe.

Endereço do hotspot

É o nome que aparece na barra do navegador na tela de login do Wi-Fi (ex.: wifi.pmapg.internal). Use um nome terminado em .internal, que é reservado para redes internas. Deixe em branco para o hotspot usar o próprio IP. Depois de trocar, quem tinha login automático (cookie) precisa entrar de novo uma vez.
