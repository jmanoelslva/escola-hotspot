Cópias de segurança

O painel guarda sozinho uma cópia por dia (no primeiro login do dia) com os usuários e senhas, aparelhos, perfis e sites bloqueados, e mantém as últimas 30 na pasta dados\backups deste computador. Restaurar recria no MikroTik só o que estiver faltando; não altera nem apaga o que já existe.

Serviço do painel

Usuário próprio do painel no MikroTik (painel-servico, grupo painel). Com ele o painel registra o uso da internet a cada 5 minutos e atende a troca de senha pelo Wi-Fi, mesmo sem ninguém logado. A senha dele fica só neste computador.

Troca de senha pelo Wi-Fi

Mostra o link "Trocar minha senha" na tela de conectado do Wi-Fi. Quem vem do Wi-Fi só consegue abrir essa página; o resto do painel continua fechado. Visitantes não trocam.

Conexão com o MikroTik

Endereço e porta da REST API do roteador. Sem porta, o painel tenta HTTPS (443) e depois HTTP (80). Se mudar só a porta, deixe o IP em branco: fica o padrão 192.168.88.1. Antes de salvar, o painel testa o endereço novo com o seu usuário; se não responder, nada muda.

Endereço do hotspot

É o nome que aparece na barra do navegador na tela de login do Wi-Fi (ex.: wifi.pmapg.internal). Use um nome terminado em .internal, que é reservado para redes internas. Deixe em branco para o hotspot usar o próprio IP. Depois de trocar, quem tinha login automático (cookie) precisa entrar de novo uma vez.

Rede Wi-Fi dos QR codes

Usada no QR code "Conecte ao Wi-Fi" dos cartões de visitante: a câmera do celular oferece entrar na rede sem digitar o nome. Deixe o nome em branco para imprimir só o QR code do login.
